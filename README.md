# vinyl-music-piayers 1.0
Vinyl Music Player — # 🎵 Vinyl Music Player

Музыкальный плеер для Android с интерфейсом в стиле классического винилового проигрывателя.

## Возможности

- 🎧 Воспроизведение музыки
- 💿 Дизайн в стиле виниловой пластинки
- 📚 Музыкальная медиатека
- ❤️ Избранное
- 📁 Папки и плейлисты
- 📻 Интернет-радио
- 🎚️ Музыкальные эффекты
- 🔔 Уведомления о воспроизводимой композиции

## Установка

Скачайте APK-файл из этого репозитория и установите приложение на Android.
